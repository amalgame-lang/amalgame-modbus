## Protocol reference

Implements Modbus TCP as specified by the Modbus Organization
("MODBUS Application Protocol Specification V1.1b3" and "MODBUS
Messaging on TCP/IP Implementation Guide V1.0b"). No third-party
code: neither libmodbus nor any other Modbus library is used.
